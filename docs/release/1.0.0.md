# AudioNotes 1.0.0

## Highlights

- Import and organize audio recordings in projects.
- Transcribe with OpenAI or download a local Whisper model for Apple Silicon.
- Generate summaries and chat with individual recordings or current project sources using configured providers.
- Extract searchable text from PDFs and images on this Mac, then export notes to Markdown or PDF.

## Privacy

AudioNotes has no behavioral analytics or remote crash reporting. Local extraction, OCR and Local Whisper run on this Mac. Cloud providers receive the content used for a request. See Settings → Privacy for details.

## Known limitations

The v1 distribution target is Apple Silicon and macOS 15+. Ollama requires separate installation. Anthropic uses a separately installed Claude Code command-line tool. Google Gemini generation, production semantic retrieval and project study-note generation are not available in this build. Large multipart transcription does not resume completed parts after the application quits. OCR and AI-generated content may contain errors; review it before relying on it.
