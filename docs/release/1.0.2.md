# Soniquill 1.0.2

- Share and import recordings as Soniquill packages with the original audio, transcript, and selected attachments.
- Publish projects to Google Drive, link or import existing Drive projects, and resolve file conflicts.
- Reuse the sharing folder when adding another project. The Share confirmation shows the destination, and Auto-Sync and Check for Changes are available in Sync Options.
- Improved project details, recording naming, playback, transcription controls, and account sign-in.
